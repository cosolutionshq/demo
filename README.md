A static, read-only tour of the real Co.Solutions interface, fed by recorded data from a fictional agency (the trial
agency), captured 2 November 2026. Served by GitHub Pages at `/demo/`.

- **WhatsApp number**: edit `tour-config.js` (`WHATSAPP_NUMBER`, digits only, international format).
- **Rebuild**: generated by `tools/static-demo/build.sh` in the product repository; do not edit the other files by hand.
